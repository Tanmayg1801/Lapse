# LAPSE
A Timelapser for my YT channel made in cpp for Linux!

# Requirements
- ffmpeg
- grim

# Features
- Takes screenshot every 5 econds.
- Stitches them into a 30fps .mp4 video.

# How to use
- Clone the repo in .local/bin (Optional, I wanted to use it from wherever in my device)
- Run `./lapse record` to start recording.
- Press `Ctrl + C` to stop.
- Run `./lapse ffmpeg` to get your video output.
